plain-app 与 plain-desktop GraphQL Schema 差异

更新于 2026-10-01 · 主 schema SDL 静态对比 · plain-app shared/apitest/schema.graphqls vs plain-desktop schema/schema.graphql

说明

签名包含参数、返回类型与 Non-Null 标记。注释、描述和 SDL 排列顺序不纳入比较。Schema 形状差异不代表 resolver 行为一定不同。

plain-app peer/guest SDL 与 desktop peer SDL 用途独立，未纳入。
