怎么看

字段签名比较包含参数名、参数类型、返回类型与 Non-Null 标记。报告只比较主 schema；plain-app 的 peer/guest SDL 与 desktop peer schema 用途独立，应另行对比。本表列出的差异是 schema 形状差异，尚未证明 resolver 行为完全相同。

处理建议：“通用契约待核对”优先逐项确认并对齐；Android 手机传感器/个人数据能力不应机械移植到桌面；desktop/NAS 文件系统、挂载、Samba、回收站和扫描能力属于产品扩展，可保留但应接受其非 plain-app 契约事实。
