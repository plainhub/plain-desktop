# emoji-shortcodes-iamcal.json

Vendored from `emojibase-data@17.0.0` (`en/shortcodes/iamcal.json`), the only
dataset this project uses. Shortcode data originally comes from
[iamcal/emoji-data](https://github.com/iamcal/emoji_data), aggregated by
[emojibase](https://github.com/milesj/emojibase) — both MIT licensed. See
`emoji-shortcodes-iamcal.LICENSE`.

Map of emoji hexcode → shortcode (string or array of strings), consumed by
`src/lib/emoji-shortcodes.ts`.

To update: replace this file with the matching file from a newer
`emojibase-data` release.
